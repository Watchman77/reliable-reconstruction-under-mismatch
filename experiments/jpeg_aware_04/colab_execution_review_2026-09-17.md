## Reconstruction result

Pooled RGB PSNR is computed from mean source MSE, not by averaging source PSNR values. Lower detail MSE is better. Each source contributes one equally sized evaluation crop per condition.

| Main method, JPEG Q75 | Pooled RGB PSNR (dB) | Mean detail MSE |
|---|---:|---:|
| Input | 29.677595 | 0.0004019989 |
| Classical inverse | 30.469349 | 0.0003790746 |
| DPIR | 30.057391 | 0.0005126495 |
| FBCNN only | 29.781192 | 0.0003858871 |
| FBCNN + classical | 30.638944 | 0.0003651317 |
| FBCNN + DPIR | **30.947555** | **0.0003495773** |

FBCNN + DPIR improves on raw DPIR by **0.890164 dB** and **31.8097% lower mean detail MSE**. It also improves on classical reconstruction by 0.478206 dB and on FBCNN + classical by 0.308611 dB. Both RGB and detail improvements over all three inverse controls occur on all four JPEG sources. Against raw DPIR, source PSNR gains are 1.527571, 0.352591, 1.400525 and 0.733434 dB for 0801–0804. These satisfy the frozen reconstruction screen.

**Uncompressed-condition cost:** adding FBCNN before DPIR worsens both RGB and detail MSE on all four uncompressed 8-bit sources. Pooled PSNR falls by 0.084454 dB; mean detail MSE rises by 0.862793%. Therefore the result does not justify universally applying JPEG preprocessing. The notebook did not run an automatic decision rule for when to apply it.

The six-main-method ranking does not establish an optimal inverse. The already saved FBCNN + DPIR component using assumed blur 1.2 has 14.7051% lower pooled JPEG RGB MSE and 6.82924% lower detail MSE than the fixed nominal 1.0 reconstruction. That is a secondary observation, not a retrospectively substituted primary endpoint. Future comparison should address baseline tuning and whether the selection advantage persists with a stronger nominal reconstruction.

## Selective-detail result

The primary comparison uses FBCNN + DPIR, JPEG Q75, all patches, and **50% retention**. Each source retains 512 of its 1,024 patches. The four sources remain the replication units; the patch count does not supply thousands of independent test images.

| Ranking | Retained detail MSE | Detail RMSE > 0.025 |
|---|---:|---:|
| Operator detail spread | **0.0001049707** | **1.5625%** |
| Whole-pipeline rotation spread | 0.0001178389 | 2.4414% |
| Reconstructed-image gradient | 0.0001474068 | 3.7598% |
| Original-measurement residual | 0.0001552522 | 5.1270% |
| Expected random retention | 0.0003495773 | 15.9424% |
| Reference-error ranking, evaluation only | 0.0000835618 | 0% |

Operator detail spread yields **10.9202% lower retained detail MSE** than whole-pipeline rotation spread, the best pooled operational control. It wins against that control on all four sources. All three pooled exceedance-rate conditions pass; no source-level tail reversal against the four primary controls occurs at this endpoint. At thresholds 0.05 and 0.10, both operator and rotation rankings have zero observed exceedances here. These zeros are not upper confidence bounds or reliability guarantees.

Secondary pooled JPEG comparisons at 75% and 90% retention and within the reference-textured quartile also favour operator detail spread over the listed primary controls. At 100% retention, rankings necessarily converge to the same error, within floating-point summation. Secondary results do not replace the predeclared primary decision. The RGB operator score remains explicitly secondary. The textured quartile uses the clean reference to define an evaluation stratum; it is not an operational texture detector available at deployment.

The operator and rotation ensembles each use 24 DRUNet calls including their shared nominal reconstruction. FBCNN costs are one versus three passes. Their total compute is not equal, and overlapping score-cost rows must not be summed as independent work. Rotation spread remains a limited heuristic comparator; no trained image-only uncertainty estimator was run.
